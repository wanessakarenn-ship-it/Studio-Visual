# MVP acceptance — expanded
Chromium tests include creation/edit/save/reload, responsive widths, local image upload and decoding, preview, download, independent unzip/Python inspection, standalone file rendering, computed style and geometry parity at three viewport widths, axe WCAG A/AA scan of exported page, 500-node browser stress test with 20 edit/undo samples and 100 ms p95 / 1 s reopen budgets. Screenshots and JSON evidence retained. Browser timing includes automation overhead and is explicitly stricter than core command-only timing. No fabricated measurements. Drag-frame latency, editor-wide accessibility, pixel-level comparison, real user studies and cross-browser validation remain separate acceptance requirements. User protocol in docs/testing/user-acceptance.md.
