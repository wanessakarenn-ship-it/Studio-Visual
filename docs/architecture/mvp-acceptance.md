# MVP browser acceptance
Chromium on GitHub Actions via isolated pinned Playwright runner; application lockfile unchanged. Tests exercise Golden Page, selection, text edits, save/reload, responsive viewport widths, image import/render, preview, export download and uncaught errors. Independent unzip and Python archive inspection verify CRC, files and asset references. Screenshots/report retained as CI artifacts. This is an initial acceptance suite, not full parity or usability certification. Drag/drop, cross-browser, 500-node performance, accessibility and standalone browser rendering remain pending. No merge/deploy.
