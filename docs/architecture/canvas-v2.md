# Experimental Canvas v2
Entry: /studio-v2.html; legacy / remains unchanged. Vite builds both entrypoints. Canvas combines schema, core, renderer and storage. Onboarding blank/example/legacy/import, hierarchical layers, selection via layers, basic properties, insert/reorder/duplicate/delete, undo/redo, local autosave and explicit backup recovery. Preview uses sandboxed iframe with fixed viewport widths; no scripts or same-origin access. Import creates a new ID, leaving source unchanged.
Limitations: no canvas click-selection, inline editing, drag and drop, asset support, project browser, or browser E2E. Property inspector is initial and token display is incomplete. Snapshot history remains provisional. Active document pointer is local only, no project list; localStorage cross-tab race remains. Switching flushes current edits; page close warns on dirty state. No deployment or merge.
